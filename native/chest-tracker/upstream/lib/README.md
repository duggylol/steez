# Replay parser

This folder is a patched copy of [FortniteReplayDecompressor](https://github.com/Shiqan/FortniteReplayDecompressor)
by Shiqan (MIT, see `LICENSE-FortniteReplayDecompressor`).

The patches are by LED-N and come from [Fortnite-ChestCounter](https://github.com/LED-N/Fortnite-ChestCounter)
at commit `21599bc` (MIT, see `LICENSE-LED-N-ChestCounter`). `PATCHES.md` lists each one. Chest Tracker
relies on them for chest blueprints the stock parser does not know, refilled chests, and the raw
ability-grant data used to count treasure-hunt gizmos.
